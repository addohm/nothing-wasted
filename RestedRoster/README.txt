Rested Roster 0.1.1 by KYOL

- Saves each character's exact rested XP when that character is played.
- Estimates rested XP forward while the character is offline.
- /rr or /restedroster shows the roster.
- /rr clear resets the saved roster and re-adds the current character.
- Normal third-party addons cannot run on the character-select screen, so the roster is shown in-game.
- Prints "Rested Roster 0.1.1 by KYOL loaded." in chat when loaded.
