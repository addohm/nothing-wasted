# Rested XP

A planned World of Warcraft addon for WoW: Forever (Interface 16001) that tracks rested XP across your
characters, including estimates for the ones you're not playing.

**Status:** planning. There's no addon code yet. An earlier 0.1.0 draft was written before the design
was settled and has been removed. Its ideas are listed in [ROADMAP.md](ROADMAP.md) for discussion.

## Repository layout

- `RestedRoster/`: an older addon kept only as an example and inspiration. The new addon won't use it.
